# Core-screen asset slot

To place the uploaded app screen inside the animated primary device, copy it to this folder using one of these names:

- `user-upload.webp` (preferred)
- `user-upload.png`
- `user-upload.jpg`
- `user-upload.jpeg`

The preview automatically uses the first matching file. Until an image is available, it displays a purpose-built finance screen so that the motion and layout can be tested end to end.
